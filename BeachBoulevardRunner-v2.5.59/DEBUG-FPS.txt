Beach Boulevard Runner v2.5.59 - hidden FPS export
==================================================

Turn it on (either way):
  1. Open the game with ?debug=fps at the end of the address, e.g.
     .../BoulevardRunner-v2.5.59-phone.html?debug=fps
  2. Or, in the game: tap SET, then press and HOLD the version label
     ("v2.5.59", top of the SET card) for about 1.2 seconds.
     Hold it again to turn it off. It is off after every reload.

Use it:
  - Close SET and run. A small "FPS DEBUG EXPORT" panel appears at the top.
    Only running frames are recorded (pause, SET open, hidden tab are skipped).
  - RESET clears the recording. Run 1-3 minutes in the setting you want to test.
  - JSON saves the full report plus every frame time; CSV saves a summary header
    plus one line per frame; COPY puts the summary on the clipboard;
    HIDE turns the panel off.

Numbers:
  avg FPS  = frames / total time
  1% low   = 1000 / average of the slowest 1% of frame times
  0.1% low = 1000 / average of the slowest 0.1% of frame times
  p50/p90/p95/p99/p99.9 = frame-time percentiles in ms (low1_p99 = 1000/p99)
  The report also has preset, weather, style, camera, average draw calls,
  screen size, pixel ratio, CPU cores, memory and GPU name.
